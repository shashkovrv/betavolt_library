# betavolt_library

Библиотека для скрининга и моделирования характеристик полупроводниковых материалов для бетавольтаических источников питания.

## Возможности

- Моделирование торможения бета-электронов в веществе (модифицированное уравнение Бете-Блоха Джоя-Ло).
- Расчет практических пробегов частиц (степенной закон Фельдмана, численное интегрирование CSDA).
- Оценка радиационной стойкости полупроводников: кинематика упругого рассеяния релятивистских электронов, расчет порогов смещения атомов решетки (модель Ван Вехтена) и сечений дефектообразования Мак-Кинли-Фешбаха.
- Расчет диодных характеристик и теоретического КПД по модели Олсена.
- Выгрузка и фильтрация кристаллических структур из Materials Project.

## Установка

Требуется Python 3.10+.

```bash
git clone https://github.com/shashkovrv/betavolt_library.git
cd betavolt_library
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

pip install -r requirements.txt
```

## Конфигурация

Для выгрузки структур из Materials Project создайте файл `.env` на основе шаблона `.env.example`:

```bash
cp .env.example .env
```

Укажите ваш API-ключ в переменной `MP_API_KEY`.

## Тестирование

Запуск тестов и проверка физических инвариантов:

```bash
pytest tests/
```

## Структура проекта

- `src/physics/` — расчетный модуль (константы, потери энергии, генерация пар, радиационные дефекты, электрические характеристики).
- `src/data/` — выгрузка и фильтрация данных Materials Project.
- `notebooks/` — исследовательские Jupyter-ноутбуки.
- `tests/` — модульные тесты и верификация физических моделей.
